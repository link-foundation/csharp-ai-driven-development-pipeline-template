JSON escaping alone cannot neutralize a legacy marker in the middle of a line.

The anchoring change proposed in this issue, with regression cases for embedded markers and preserved deliberate line-leading commands, would let consumers remove this duplicated protection. A supported toolkit literal-output primitive could also centralize it for callers that still need compatibility with older runners.
